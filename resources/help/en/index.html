EasyRPG Editor Help

The EasyRPG Editor lets you make games compatible with RPG Maker 2000 and RPG Maker 2003, played with EasyRPG Player. In each window, the Help button opens the matching section of this page.

Project and maps

The Editor remembers window sizes and positions, docked panel sizes and placement, splitter widths, table columns, database and event pages, selections, scroll positions and each project's open maps, tile brushes, layers and zoom. In Settings, choose Reset local state to restore these defaults immediately. Game files, unsaved edits, the Player and RTP paths, language and other preferences are kept.

New project

Creates an empty game folder ready to be played with EasyRPG Player.

  • Game Title: the name shown in the window title of the game.
  • Game Folder: the name of the folder created for the project, inside the Path to games folder.
  • DB template: the starting database (heroes, items, chipsets...) copied into the new project.
  • Tile Size: size of one map tile in pixels. RPG Maker 2000/2003 games always use 16; larger sizes only work with EasyRPG Player.

Project settings

Game Project > Project Settings (or Settings... in the list of projects) has three pages:

  • General: the Directory Name and Game Name (as RPG Maker's Rename Project), and the Encoding of the texts ([EasyRPG] Encoding of RPG_RT.ini). Texts shown garbled usually mean a wrong one: the project is closed (asking to save it) and opened again in the one chosen.
  • Engine: the format of the project (Convert to RPG Maker 2003... converts it, after a backup), the players in the game folder with their version (RPG_RT.exe of RPG Maker 2000 or 2003, the Maniac Patch, EasyRPG Player), the Text font of the game (saved in the database, with a sentence drawn as EasyRPG Player draws it), the fonts RPG_RT.exe asks Windows for, and the symbols of messages ($A...).
  • EasyRPG Player: what only EasyRPG Player reads; RPG_RT.exe is not changed. Patches are detected from the game files as the Player does, chosen (written in the [Patch] section of EasyRPG.ini), or taken as written in EasyRPG.ini, which the Editor then leaves as it is (the choice when EasyRPG.ini sets other options, such as AntiLagSwitch). Point at a patch to see what it changes. The Maniac Patch adds its commands to the Event Commands window. Fonts: the Player's own, or a font file copied in the Font folder of the game (Choose...).

Open EasyRPG.ini opens the file in the script editor of the Editor settings (created if missing), for the options not shown here; the window reads it again when you come back. Only the lines changed are written: the rest of RPG_RT.ini and EasyRPG.ini stays as it is.

Maps and drawing

The map tree on the left lists every map of the project. Double-click a map to open it, right-click to create a new map, open its properties, copy, paste or delete it. Drag a map onto another one to make it a child map: child maps can inherit the music, battle background and permissions of their parent. Areas are rectangles of a parent map that have their own list of random encounters.

A map has three layers. Choose the layer to edit with the toolbar or the keys:

  • Lower layer (F5): ground, water, walls and autotiles.
  • Upper layer (F6): decorations drawn over the ground (trees, furniture, roofs).
  • Events (F7): double-click a tile to create or edit an event, drag an event to move it, right-click to copy, paste or delete it.

Drawing tools: Pen draws tile by tile, Rectangle fills a rectangle, Circle fills an ellipse, Fill replaces a whole area of identical tiles. Pick tiles in the chipset palette; you can select several tiles at once to stamp a block. Use Zoom In, Zoom Out and Zoom 100% to change the view. Save Map (Ctrl+S) writes your changes, Revert Map (Ctrl+R) discards them, Ctrl+Z undoes the last change.

Map properties

  • Name: shown in the map tree (not in the game).
  • Chipset: the tile set used to draw the map.
  • Width / Height: map size in tiles (minimum 20 × 15, the size of the screen).
  • Scroll type: no loop, vertical loop, horizontal loop or both. A looping map wraps around when the hero walks past its edge.
  • Parallax background: an image shown behind transparent tiles, with optional horizontal/vertical scrolling and auto-scroll speed.
  • BGM: inherit from the parent map, keep what an event set, or play a specific music.
  • Battle background: inherit from parent, use the terrain background, or a specific image.
  • Teleport / Escape / Save: inherit, allow or forbid the Teleport and Escape skills and saving on this map.
  • Encounters: the monster groups that can attack the hero on this map and the average number of steps between battles.

Random dungeon generation: enable Use Random Dungeon Generator, choose a layout and the ceiling, wall and floor tiles, then click OK to apply the settings. Choose distinct ceiling and floor tiles; identical tiles make the generated layout look uniform. Right-click the map in the map tree and choose Generate Dungeon to create and open a new child map. This uses the current settings, including changes in an unsaved map tab. The source map is preserved.

In the original RPG Maker 2003 player, the checkbox also makes the dungeon regenerate whenever the map is entered during play. EasyRPG Player currently does not implement that runtime generation; use the Editor's Generate Dungeon command to create the playable layout.

Search

Finds where something is used in your events.

  • Search bar: enter an exact ID, part of a variable, switch, item or event name, or event text. Suggestions show the ID, type and name, with exact matches first across all types. Picking a suggestion also selects its type filter. Press Enter or click Search.
  • Type: narrow results to variables, switches, items, event names or event text, or search all types. Variable searches include reads, writes, ranges and event page conditions.
  • Scope: Whole project searches every map and common event; Current map searches the open map, including unsaved edits; Common events searches only common events.
  • Results: every event page and command that matches, with its type and an event graphic when available. Click a map event to select its cell on the map. Click a common event to open it in the database; command matches are selected and scrolled into view. Press Enter to open the selected result.

Test play

Play Test (F4) saves your work and starts the game in EasyRPG Player in test mode (F9 opens the debug menu in game, Ctrl lets the hero walk through walls).

  • Play mode: New Game, Load savegame (pick a slot), or Test Battle against a monster group, with a chosen party, levels, equipment, formation and battle background.
  • Replace initial party / starting position: start with another party or at another place than the ones set in the database.
  • Options: window or fullscreen, disable music, sound effects or random encounters, and disable the RTP.

RTP path

The RTP (Run Time Package) is the set of standard graphics and sounds of RPG Maker 2000/2003. Games that use RTP files do not include them, so the Editor needs to know where the RTP is installed. Set Path to RTP to the RTP folder (the one containing CharSet, ChipSet, Music...). Files in your project always take priority over RTP files with the same name.

Reload files changed on disk

Option in the Tools menu. When another program writes the project files (for example a script or a sync tool that edits the database or maps as text), the Editor reloads the database, the map tree and the open maps automatically. It is off by default. If you have unsaved changes in the Editor, it asks before discarding them.

Screenshots

Press Ctrl+Alt+S (Cmd+Option+S on macOS) to save a picture of the active window, dialog included. The file is written in the Pictures/EasyRPG Editor folder of your user account.

Events

Event window

Events are placed on the event layer of the map: click a cell to select it, or move the selected cell with the arrow keys; Enter then edits its event, or creates one on an empty cell.

An event is anything on the map that can act: a person, a chest, a door, a hidden trigger. It has one or more pages. During the game, the page with the highest number whose conditions are all met is the active one; if no page qualifies, the event is not there.

  • Name: for your own reference.
  • New / Copy / Paste / Delete / Clear page: add a page, copy the current page, paste a copied page, remove the current page, or reset it to empty.

Conditions (all checked conditions must be true):

  • Switch (two of them): the switch must be ON.
  • Variable: the variable compared to a number. RPG Maker 2000 only checks "greater than or equal"; the other comparisons (=, ≤, >, <, ≠) are RPG Maker 2003 only.
  • Item: the party owns this item.
  • Hero: this hero is in the party.
  • Timer: the timer is at or below the given minutes and seconds. Timer 2 is RPG Maker 2003 only.

Graphic: the charset sprite (or a tile of the upper layer) shown for the event. Leave it empty for an invisible event. Set chooses a character, a tile or no graphic; a click on the graphic changes it in the same kind (the tiles for a tile). In the tiles, a click selects one and a double-click takes it. A tile sets the Layer from its passability in the chipset: a blocking tile (×) is on the hero's layer, a tile walked on (○) below the hero, a star (☆) above. An event without a graphic opens the characters on the first charset.

Trigger (what starts the commands):

  • Action Key: the hero faces the event and presses the action key (or bumps into it, for events on the same layer as the hero).
  • Touched by Hero: the hero walks into or onto the event.
  • Collision with Hero: the event touches the hero, or the hero touches it.
  • Autostart: starts as soon as the page is active and repeats as long as it stays active; the player cannot move meanwhile. Turn a switch off or erase the event to stop it.
  • Parallel Process: runs in a loop in the background while the game continues.

Layer: Below hero (the hero walks over it), Same as hero (blocks the way like a character), Above hero (drawn over the hero). Forbid event overlap keeps other events from moving onto the same tile, even when they are on another layer.

Movement: Type is Stationary, Random, Up and down, Left and right, Toward hero, Away from hero, or Custom (click Edit route to write a move pattern that repeats). Frequency (1 to 8) is how often the event moves, Speed (1 = 1/8 normal to 6 = 4× normal) how fast.

Animation type: Standing animation (steps only while moving), Walking animation (steps all the time), Fixed direction with standing or walking animation (never turns), Fixed graphic (no animation), Spin.

Commands: the list on the right is what the event does, from top to bottom.

  • Double-click a line or press Enter to insert a command before it (opens the Event Commands window); on a <> line it goes at the end of the list or block. The selection stays on the line, so the next command goes under the new one.
  • Space, or a click on the command already selected, edits it; Delete removes it.
  • A new command opens with the settings last accepted in its window, in this game, also after a restart (the same variable and operation, the same condition, with or without an else part...). Messages, comments and choices start empty.
  • The arrow keys go from command to command: the next lines of a message, : Else and : End are skipped, and Left and Right work like Up and Down. Page Up and Page Down move by half a list (pressed elsewhere in the window, they first go back to the list); Ctrl+Tab and Ctrl+Shift+Tab switch event pages (the Control key on macOS too). With Shift, the keys select several commands.
  • Ctrl+C, Ctrl+X and Ctrl+V copy, cut and paste whole commands; a branch, choice or loop is copied with everything inside it. The commands copied can also be pasted as text in a text editor, as the lines of the list.

Event Commands window

Lists every event command, grouped in tabs (messages, game progression, map, screen, sound, flow control...). Click a command to add it. Type in the search field to filter the list by name in all tabs at once; Enter picks the best match. Commands that do not exist in the current game type (RPG Maker 2000 or 2003) are not shown.

Move route

Builds a list of moves for an event or the hero. Click a button on the right to add a move after the selected one; double-click a move to change it, Delete removes it.

  • Moves: step in 8 directions, random step, step toward or away from the hero, step forward; face a direction, turn 90° left/right, turn 180°, face hero, face away from hero; wait; begin and end jump; lock and unlock facing; increase or decrease speed and frequency; phasing mode on/off (walk through obstacles); stop and resume animation; increase or decrease transparency.
  • Switch ON / Switch OFF: turns a switch on or off when the move is reached.
  • Change Graphic: choose a new charset and sprite for the moving character.
  • Play Sound Effect: a sound file with volume, tempo and balance.
  • Repeat: start over at the end of the list.
  • Skip impossible moves: if a move is blocked, go to the next one instead of waiting.
  • Target and Frequency (only in the Move Event command): which character moves (hero, this event, a vehicle or another event) and how often it moves.

Database

Database overview

The database (F8) holds everything that is shared by the whole game: heroes, skills, items, monsters, chipsets, words used by the menus, music and more. Each tab has a list on the left; select an entry to edit it on the right. Click OK or Apply to keep your changes. Tabs marked RPG Maker 2003 are only shown for 2003 projects.

Names, descriptions and other texts the game shows are in a monospaced font, with a thin vertical line where RPG Maker stops typing (for example 12 characters for a hero name, 20 for an item name, 50 for an item description): text after the line may not fit in the game window. The Editor does not cut longer text.

Heroes

The characters who can join the party.

  • Name, Title, Charset (map sprite), Face, and in RPG Maker 2003 the Class and Battler (side-view battle graphic).
  • Initial / Maximum level, Critical hits (chance of a critical hit), Experience curve.
  • Options: Two weapons, Lock equipment, AI controlled in battle, Strong defense.
  • Parameter curves for Max HP, Max MP, Attack, Defense, Spirit and Agility at each level.
  • Initial equipment, Skills learned at each level, Attribute and Condition resistance (A = most affected, E = least affected), unarmed battle animation, and in RPG Maker 2003 the Battle commands.

Classes (RPG Maker 2003)

A class is a template for heroes: parameter curves, experience curve, skills learned by level, battle commands, battler animation and resistances. A hero takes the values of his class when it is set or changed with Change Class.

Skills

  • Name, Description, Message shown when used, MP cost (also as a % of max MP in RPG Maker 2003).
  • Type: Normal (damage, healing, conditions), Teleport, Escape, or Switch (turns a switch on; usable on the map and/or in battle). RPG Maker 2003 adds custom skill groups.
  • Target: one enemy, all enemies, user, one ally, all allies.
  • Effect rating (base power), Attack/Spirit influence, Variance, Success rate, Battle animation.
  • Affected parameters (HP, MP, Attack...), absorb or ignore defense, Attributes and Conditions it inflicts or cures.

Items

  • Name, Description, Price (0 = cannot be sold).
  • Type: Common item, Weapon, Shield, Armor, Helmet, Accessory, Medicine, Book (teaches a skill), Seed (raises a parameter), Special (uses a skill), Switch (turns a switch on).
  • Uses (0 = unlimited), which heroes (or classes in RPG Maker 2003) can use or equip it, parameter bonuses, hit rate and critical chance for weapons, attributes and conditions.

Monsters

  • Name, Battler graphic with Hue, Transparent and Flying options.
  • Max HP, Max MP, Attack, Defense, Spirit, Agility; Experience and Money earned; Item dropped and drop chance; critical hits.
  • Attribute and condition resistance.
  • Action patterns: what the monster can do (attack, defend, skill, transform, escape...), each with a condition (turn, HP, MP, party level, switch) and a priority; actions with higher priority are chosen more often.

Monster Groups

The groups of monsters the party fights. Place the monsters on the battle screen preview; a monster can be hidden at the start (revealed with Show Hidden Monster). Terrain sets on which terrains the group can appear in random encounters. The lower part holds battle events: pages of commands that run during the battle when their conditions (switches, variables, turn number, monster or hero HP, and more in RPG Maker 2003) are met. See Battle events.

Battle event triggers. The Trigger line above the commands of a page sums up when the page runs; its "..." button opens Define Battle Event Triggers, where you tick the conditions that must all be true: one or two switches ON, a variable at or above a value, the turns elapsed (a x + b: every a turns starting at turn b, or only turn b when a is 0), the HP of a monster of the group or of a hero between two percentages. RPG Maker 2003 adds the party's exhaustion, the turns taken by one monster or one hero, and a hero using a battle command (shown but disabled in RPG Maker 2000 games). A page with no condition ticked never runs.

Attributes

Elements and weapon kinds (Sword, Fire, Ice...). Each attribute is Physical or Magical and has five damage rates, A to E. Heroes, monsters and armors use the letters to say how much damage they take from that attribute (A = the most damage, E = the least).

Conditions

States such as Poison, Sleep or Confusion.

  • Name, Color, Priority, Lasts only in battle or after battle too.
  • Restriction: none, cannot act, attacks enemies at random, attacks allies at random.
  • Chance per letter A to E, parameter changes (×2, ×½), recovery chance each turn or when hit, HP and MP damage per turn or per step, skills blocked, and the messages shown.
  • Condition 1 is always "Death".

Battle Animations

Animations played for attacks and skills. Choose the animation graphic, the target (each target or the whole screen) and the vertical position. Edit each frame by placing cells from the graphic. Timing adds sound effects and screen or target flashes at given frames. Use Play to preview.

Battler Animations (RPG Maker 2003)

The side-view hero animations. Each set gives a pose (standing, attacking, using a skill, damaged, dead, victory...) from a battle charset or a battle animation, and weapon animations shown when attacking. Also choose the animation display speed.

Battle Screen (RPG Maker 2003)

The battle layout: Battle type Traditional, Alternative or Gauge, transparent windows, the window size, automatic or manual placement of heroes, and the list of Battle commands (Attack, Skill, Defend, Item, Escape, custom skill groups...) that heroes can have.

Terrain

  • Name, Damage per step (positive hurts, like lava), Encounter rate multiplier.
  • Battle background used when a fight starts on this terrain (RPG Maker 2003 can also use two scrolling frames).
  • Which vehicles can pass (boat, ship, airship) and whether the airship can land.
  • Hero graphic: normal, upper half transparent (bushes) or fully transparent; step sound (RPG Maker 2003).
  • RPG Maker 2003: chances of special battle formations (back attack, pincer, surround) on this terrain.

Chipset

A chipset is a tile set: one ChipSet graphic plus the rules of each tile. Switch between the Lower layer and Upper layer tabs, then choose an editing mode:

  • Terrain: pick a terrain, then click lower-layer tiles to assign it.
  • Passability: click to cycle: ○ passable, × blocked, ☆ drawn above the hero (the hero can walk "under" it, like a treetop or a roof edge). Right click goes back one step.
  • Directions: click the side of a tile to allow or block walking through that side (for cliffs, fences, ledges).
  • Counter (upper layer): □ marks a counter; the hero can talk with an event on the other side of it, like a shop keeper.
  • Water animation: Sequence 1-2-3-2 or 1-2-3, and Speed slow or fast.

Vocabulary

All the words and messages of the game: battle messages ("X attacks!", "Victory!"...), shop and inn texts, menu commands, parameter names, the currency unit, level-up and game-over texts. Translate or rename them here.

System

  • Initial party (up to 4 heroes).
  • Title and Game Over screen images, System graphic (window skin, cursor, font colors), wallpaper stretched or tiled, and the font (RPG Maker 2000).
  • Vehicle charsets (boat, ship, airship).
  • Music: title, battle, victory, inn, vehicles, game over.
  • Sound effects: cursor, decision, cancel, buzzer, battle start, escape, attacks, damage, evasion, enemy death, item use.
  • Screen transitions for teleports and battles, and the battle test setup.

System 2 (RPG Maker 2003)

Settings added by RPG Maker 2003: the commands of the main menu and their order, a Frame image drawn over the whole screen, window options, and what happens when the party is defeated in a random encounter (game over, or teleport and call a common event).

Common Events

Events that do not belong to a map and can be used anywhere. Trigger: Call (only runs when called by Call Event), Autostart or Parallel Process (both only while the chosen condition switch is ON, on every map). Write the commands as in the event window.

Switches and variables

Switches are ON/OFF flags that remember what the player did (door opened, quest done). Variables hold whole numbers (from -999,999 to 999,999 in RPG Maker 2000, -9,999,999 to 9,999,999 in RPG Maker 2003) such as counters, coordinates or choices. All switches are OFF and all variables 0 when a new game starts. As in RPG Maker, they are not in the database: name them with the "..." button next to a switch or variable in an event command or an event page condition; names are only for you.

Set Maximum Number changes how many switches or variables are available. Enter the new number and confirm to update the list, then select an entry to edit its name. Increasing the maximum keeps the existing names and adds empty entries. Decreasing it removes entries above the new maximum. The picker’s OK or Apply keeps your changes; Cancel discards changes you have not applied.

Choose a graphic or sound

Select a file in the list to preview it. The picker includes files from your project and the configured RTP; a project file takes priority when both have the same name. For a charset or faceset, click the character or face in the preview to choose it. For music or sound effects, use the preview controls to listen and adjust volume, tempo or balance.

OK applies the selected file and closes the picker. Apply applies it while keeping the picker open. Cancel closes it without applying the current selection. Use the Resource Manager to import or export files.

Event commands

Messages

Show Message

Shows text in a message window, 4 lines at a time. Codes in the text: \v[n] value of variable n, \n[n] hero name, \c[n] color, \s[n] text speed, \$ money window, \! wait for a key, \. and \| short and long pauses, \^ close without waiting. Add Code types them for you (each one explained by its tooltip), and the symbols $A to $z of the game's font. The lines in the text mark 38 characters (the width of a message with a face) and 50. Ctrl+Backspace (Cmd or Control on macOS) deletes the line before the cursor, as in VS Code; at the start of a line, it joins it to the line above.

Message Options

Sets how the next messages look: window normal or transparent, position top, middle or bottom, avoid covering the hero, and allow other events to move while a message is shown.

Select Face Graphic

Chooses the face shown in the next messages, on the left or right, optionally mirrored. Choose no face to remove it.

Show Choices

Shows up to 4 choices; each one gets a branch with its own commands. Cancel: forbid it, run the branch of one of the choices, or use a separate cancel branch. Put a Show Message just before to ask the question.

Input Number

Lets the player enter a number with the chosen number of digits, stored in a variable.

Game progression

Control Switches

Turns ON, turns OFF or toggles one switch, a range of switches, or the switch whose number is in a variable.

Control Variables

Changes one variable, a range, or the variable whose number is in another variable. Operation: set, add, subtract, multiply, divide, modulo. Operand: a number, another variable, a variable reference, a random number, the count of an item, a hero parameter, an event's position or direction, or other values (money, timer, party size, saves, battles, play time...).

Timer Operation

Sets the timer to a time, starts it (counting down, optionally shown on screen and running during battles) or stops it. When it reaches 0, nothing happens by itself: test it in a page condition or Conditional Branch. RPG Maker 2003 has a second timer.

Change Money

Adds or removes money, by a fixed amount or the value of a variable.

Change Items

Adds or removes some copies of an item (fixed or from variables). The party can hold up to 99 of each item.

Change Party Members

Adds a hero to the party or removes one (fixed or from a variable). The party holds at most 4 heroes.

Heroes

Change Experience

Adds or removes experience points to one hero or the whole party; option to show the level-up message.

Change Level

Raises or lowers the level of one hero or the whole party; option to show the level-up message.

Change Parameters

Raises or lowers Max HP, Max MP, Attack, Defense, Spirit or Agility of a hero permanently.

Change Skills

Teaches a skill to a hero or makes him forget it.

Change Equipment

Equips an item on a hero (it must be in the inventory, otherwise it is added), or removes the equipment of one slot or all slots.

Change HP

Adds or removes HP. Option: allow the hero to die from this damage (otherwise HP stops at 1).

Change MP

Adds or removes MP of a hero or the party.

Change Condition

Inflicts or removes a condition (Poison, Death...) on a hero or the party.

Full Heal

Restores all HP and MP and removes all conditions of a hero or the party.

Simulated Attack

Damages heroes as if attacked: base power, defense and spirit influence, variance. Option to store the damage in a variable.

Change Class (RPG Maker 2003)

Gives a hero (or the whole party) another class, or none. Options: go back to level 1; skills: keep them, replace them with those of the new class, or add those; parameters: keep them, halve them, use the level 1 values of the new class, or its values at the current level; show a message for each skill learned.

Change Battle Commands (RPG Maker 2003)

Adds or removes a battle command (or all of them) for a hero.

Change Hero Name

Renames a hero.

Change Hero Title

Changes the title (degree) shown under a hero's name in the menu.

Change Hero Graphic

Changes the charset sprite of a hero on the map; option to make it semi-transparent.

Change Hero Face

Changes the face of a hero shown in the menus.

Change Vehicle Graphic

Changes the sprite of the boat, ship or airship.

System

Change System BGM

Changes the music of battles, victory, inn, boat, ship, airship or game over.

Change System Sound Effect

Changes a system sound: cursor, decision, cancel, buzzer, battle start, escape, attacks, damage, evasion, enemy death or item use.

Change System Graphic

Changes the window skin, with the wallpaper stretched or tiled (and the font in RPG Maker 2000).

Change Screen Transitions

Changes the transition used to hide or show the screen for teleports, battle start and battle end (fade, dissolve, blinds, mosaic...).

Open Save Menu

Opens the save screen.

Change Save Access

Allows or forbids saving from the main menu.

Open Main Menu

Opens the main menu.

Change Main Menu Access

Allows or forbids opening the main menu with the cancel key.

Game Over

Shows the game over screen, then goes back to the title screen.

Return to Title Screen

Ends the game and goes back to the title screen.

Open Load Menu (RPG Maker 2003)

Opens the load screen. Added in RPG Maker 2003 version 1.12.

Exit Game (RPG Maker 2003)

Closes the game. Added in RPG Maker 2003 version 1.12.

Toggle ATB Mode (RPG Maker 2003)

Switches battles between Active mode (time keeps running while choosing) and Wait mode.

Toggle Fullscreen (RPG Maker 2003)

Switches between window and fullscreen. Added in RPG Maker 2003 version 1.12.

Open Video Options (RPG Maker 2003)

Opens the video settings window. Added in RPG Maker 2003 version 1.12; in EasyRPG Player it opens the Player settings.

Scenes

Start Combat

Starts a battle against a monster group (fixed or from a variable). Background: from the map/terrain or a specific image (RPG Maker 2003 adds the formation: normal, back attack, surround, pincer). Escape: forbidden, ends the event, or runs a branch. Defeat: game over or a branch. First strike gives the party the first turn.

Open Shop

Opens a shop: buy and sell, buy only, or sell only; one of three message styles; the list of items for sale. Option to add a branch for "made a transaction" and "left without buying".

Show Inn

Offers to rest for a price: if accepted, the screen fades, the party is fully healed and the inn music plays. Two message styles; option for a "stayed" / "did not stay" branch.

Enter Hero Name

Opens the name entry screen for a hero. Choose the starting character set (letters or symbols, or Japanese in the original) and whether the current name is shown.

Map and movement

Teleport

Moves the party to a map and a position: choose the map and enter X and Y coordinates. Retain the current facing direction, or choose a new facing direction in RPG Maker 2003.

Memorize Location

Stores the current map ID, X and Y of the hero in three variables.

Recall to Location

Teleports the party to the map ID, X and Y stored in three variables.

Enter/Exit Vehicle

Makes the hero board the vehicle in front of him, or leave the current one.

Set Vehicle Location

Places the boat, ship or airship on a map and position (fixed or from variables).

Set Event Location

Moves the hero, a vehicle or an event instantly to another position of the current map (fixed or from variables). RPG Maker 2003 can set the facing direction when using fixed coordinates.

Swap Event Locations

Swaps the positions of two events.

Get Terrain ID

Stores in a variable the terrain number of a map tile (fixed or from variables).

Get Event ID

Stores in a variable the ID of the event standing on a tile (0 if none).

Show Battle Animation

Plays a battle animation on the hero or an event on the map, or over the whole screen. Option to wait until it ends.

Hero Visibility

Hides or shows the hero sprite (useful for cutscenes). The hero still moves and blocks the way while hidden.

Flash Event

Makes the hero or an event flash with a color, strength and duration; option to wait.

Move Event

Gives a move route to the hero, an event or a vehicle, with a frequency, and the Repeat and Skip impossible moves options. The event continues to the next command right away; use Proceed with Movement to wait.

Proceed with Movement

Waits until all move routes started by Move Event are finished. Do not use it with repeating routes, or the event waits forever.

Halt All Movement

Cancels all move routes given by Move Event.

Change Chipset

Changes the chipset of the current map until the hero leaves it.

Change Parallax Background

Changes the parallax background image of the current map and its scrolling settings.

Change Encounter Rate

Changes the average number of steps between random battles on the current map.

Change Tile

Replaces every use of one tile by another tile on the lower or upper layer of the current map (for example to open all doors of a kind).

Teleport Targets

Adds or removes a destination for the Teleport skill: a map, a position, and optionally a switch turned ON on arrival.

Change Teleport Access

Allows or forbids Teleport skills.

Escape Target

Sets where the Escape skill takes the party (map, position, optional switch).

Change Escape Access

Allows or forbids Escape skills.

Screen and pictures

Hide Screen

Hides the screen with a transition (fade, dissolve, blinds...) or the default teleport transition. The screen stays black until Show Screen.

Show Screen

Shows the screen again with a transition.

Tint Screen

Changes the colors of the screen: red, green, blue (100% = normal) and saturation, over a duration in tenths of a second; option to wait.

Flash Screen

Flashes the screen with a color and strength for a duration; option to wait. RPG Maker 2003 can also flash continuously and stop it.

Shake Screen

Shakes the screen with a strength, speed and duration; option to wait. RPG Maker 2003 can also shake continuously and stop it.

Pan Screen

Locks or unlocks the camera, pans it in a direction by a number of tiles, or returns it to the hero. Pan and return operations have a movement speed and an option to wait until completion.

Weather Effects

None, rain or snow, with a strength (weak, medium, strong). RPG Maker 2003 adds fog and sandstorm.

Show Picture

Displays a numbered picture from the Picture folder, at fixed coordinates or coordinates stored in variables. Choose whether it follows the map, the transparent color, magnification and transparency, then set red, green, blue, saturation and rotation or waving on Additional Attributes. RPG Maker 2003 supports separate top and bottom transparency. Later picture extensions are preserved when editing the standard controls.

Move Picture

Changes the position, magnification, transparency, tint and effects of a numbered picture over a duration in tenths of a second. Coordinates can come from variables; an option waits for completion. RPG Maker 2003 supports separate top and bottom transparency. The picture image is retained.

Erase Picture

Removes a picture from the screen.

Sound and movie

Play BGM

Plays background music with fade-in time, volume, tempo and balance. "(OFF)" stops the music.

Fade Out BGM

Fades out the music over the chosen time, in milliseconds (1000 = 1 second).

Memorize BGM

Remembers the music currently playing.

Play Memorized BGM

Plays again the music remembered by Memorize BGM.

Play Sound Effect

Plays a sound effect with volume, tempo and balance.

Play Movie

Plays a video file (AVI or MPEG) at a position and size. EasyRPG Player does not play movies and skips this command.

Flow control

Conditional Branch

Runs commands only if a condition is true, with an optional "Else" branch. Conditions: a switch, a variable compared to a number or a variable, the timer, money, an item owned, a hero (in party, name, level, HP, skill, equipment, condition), an event's direction, the vehicle in use, the event started by the Action Key, or the music has played once. RPG Maker 2003 adds Timer 2 and other tests. The RPG Maker 2003 Other tests cover a save file, Test Play, ATB Wait mode and fullscreen. Removing a populated else handler requires confirmation; declining preserves the block.

Label

Marks a place in the command list with a number, to jump to with Jump to Label.

Jump to Label

Continues from the label with that number in the same event page.

Loop

Repeats the commands inside it forever, until Break Loop.

Break Loop

Leaves the loop it is in and continues after the end of the loop.

End Event Processing

Stops the commands of this event page right now.

Erase Event

Removes this event from the map until the map is entered again. To remove it for good, use a switch and an empty page.

Call Event

Runs a common event, or a page of an event on the current map (fixed or from variables), then comes back and continues.

Comment

A note for yourself; it does nothing in the game.

Key Input Processing

Stores the pressed key code in a variable: down 1, left 2, right 3, up 4, decision 5, cancel 6, Shift 7. Choose individual arrows, decision, cancel and Shift, and whether to wait or read the current input. RPG Maker 2003 adds number keys (10–19), operator keys (20–24) and elapsed-time storage in tenths of a second while waiting. Older parameter layouts are upgraded only when an edited option needs the newer layout.

Wait

Pauses the event for a time in tenths of a second. RPG Maker 2003 can also wait until a key is pressed.

Battle events

These commands are used in the battle events of a monster group.

Change Monster HP

Adds or removes HP of a monster: a fixed amount, the value of a variable, or a percentage of its current HP. Option to let the change kill the monster.

Change Monster MP

Adds or removes MP of a monster.

Change Monster Condition

Inflicts or removes a condition on a monster.

Show Hidden Monster

Makes a monster that was hidden at the start of the battle appear.

Change Battle Background

Changes the background image of the current battle.

Show Battle Animation (battle)

Plays a battle animation on one monster, all monsters or (in RPG Maker 2003) a hero; option to wait.

Conditional Branch (battle)

Tests a switch or variable, whether a hero or monster can act, or (RPG Maker 2003) the current monster target or a hero’s battle command. Add an else handler if needed. Removing a handler containing commands requires confirmation; declining leaves the editor open and preserves the block.

End Battle

Ends the battle immediately, without victory or defeat.

Call Common Event (RPG Maker 2003)

Runs a common event during the battle, then continues.

Force Flee (RPG Maker 2003)

Makes the party, all monsters or one monster flee the battle. Option: nothing happens when the target is surrounded (the party in a pincer attack, the monsters in a surround attack).

Enable Combo (RPG Maker 2003)

Makes a hero repeat a battle command (such as Attack) several times in one turn.

Maniac Patch commands

Commands added by the Maniac Patch. They are in the Maniac Patch page of the command list, enabled when the game uses the patch (as EasyRPG Player detects it: a [Patch] section with Maniac=1 in EasyRPG.ini, a Maniac RPG_RT.exe, or accord.dll in the game folder). In other games they are shown and kept but cannot be added.

Get Save Info (Maniac Patch)

Reads a save slot (number or variable) without loading it: its date and time, the level, HP and names of the heroes, into variables and strings, and shows their faces as pictures.

Save Game (Maniac Patch)

Saves the game into a slot (number or variable) without the save screen; a switch can tell whether it worked.

Load Game (Maniac Patch)

Loads a slot (number or variable) without the load screen; a switch can tell whether the slot exists.

End Load Process (Maniac Patch)

Ends the processing that runs after a game loaded with Load Game, and gives control back to the player.

Control Global Save (Maniac Patch)

Reads and writes switches and variables kept in a file shared by all the saves (unlockables, settings...).

Get Mouse Position (Maniac Patch)

Stores the position of the mouse pointer on the game screen into two variables.

Set Mouse Position (Maniac Patch)

Moves the mouse pointer to a position of the game screen (numbers or variables).

Key Input Processing Ex (Maniac Patch)

Reads the state of any keyboard key or mouse button into variables, beyond the keys of Key Input Processing.

Show String Picture (Maniac Patch)

Shows a text as a picture: the text (or a string variable), font, size, spacing, a window from the system graphic, and the effects of Show Picture.

Get Picture Info (Maniac Patch)

Stores the position, size, or the color of a pixel of a picture into variables.

Change Picture ID (Maniac Patch)

Gives pictures other numbers, which changes the order they are drawn in.

Edit Picture (Maniac Patch)

Changes a shown picture: draws on it, copies parts of other pictures or of the screen.

Write Picture (Maniac Patch)

Saves a picture, or the screen, to an image file of the game folder.

Control Battle (Maniac Patch)

Changes the running battle: pauses the gauges, forbids actions, sets the speed of the battle...

Control ATB Gauge (Maniac Patch)

Sets, adds to or reads the active time gauge of heroes or monsters (a value or a percentage).

Change Battle Command Ex (Maniac Patch)

Shows or hides the extra battle commands, such as Row and Fight / Auto Battle / Escape.

Get Battle Info (Maniac Patch)

Stores information about a hero or monster in battle (state, position, gauge...) into variables.

Control Variable Array (Maniac Patch)

Applies an operation to a range of variables at once: copy, swap, fill, sort, shuffle...

Control Strings (Maniac Patch)

Operates on the string variables: set, join, insert, replace, search, split, convert to and from numbers, read and write files...

Rewrite Map (Maniac Patch)

Replaces the tiles of a rectangle of the map with other tiles, until the map is left.

Edit Tile (Maniac Patch)

Changes one tile of the map (numbers or variables).

Get Game Info (Maniac Patch)

Stores information about the game into variables: map size, tile ids, screen size, event positions, the number of the current map...

Set Game Option (Maniac Patch)

Changes options of the game while it runs, such as the size of the face graphics or how messages are shown.

Call Command (Maniac Patch)

Runs any event command whose code and parameters come from variables.

Control Text Processing (Maniac Patch)

Changes how the control codes of messages and strings (\V, \T...) are processed.

Add Move Route (Maniac Patch)

Adds moves to the route of an event. Its parameters are edited with Edit raw.

Zoom (Maniac Patch)

Zooms the game screen in or out around a point, at a chosen speed.

Resource Manager

Tools > Resource Manager lists the files of the game, folder by folder (CharSet, ChipSet, Music...), with the files of the RTP marked (RTP): a file of the game hides the RTP file of the same name, as in the games. A folder the game does not have is shown in italics. The filter field narrows the list; the preview shows a picture with its transparent color, or plays a music or sound.

Import copies files into the selected folder (created if needed). A picture is checked against RPG Maker's sizes and kept with 256 colors (reduced if it has more, or kept in true color, which only EasyRPG Player shows); for the folders whose pictures have a transparent color, click that color in the picture. Pictures are saved as PNG or as XYZ. Export copies a file, of the game or of the RTP, elsewhere. Delete moves a file of the game to the trash (RTP files cannot be deleted).
