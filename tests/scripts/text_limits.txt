# The texts of the database are in a monospaced font, with a line where
# RPG Maker stops typing (an item description: 50 characters). Longer text
# still goes in. Nothing is saved.
action actionDatabase
tab tabOld_Pages 3
focus itemDescription
key End
type - and more text that goes past the line
expect itemDescription Recovers 50 HP.- and more text that goes past the line
check-layout
tab tabOld_Pages 13
check-layout
close
quit
