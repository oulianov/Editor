# Game Project > Project Settings: the folder and title, the encoding, the
# engine and fonts, and what only EasyRPG Player reads (patches, fonts).
# TestGame-2003: its EasyRPG.ini chooses patches, with AntiLagSwitch and
# DirectMenu (so the Player does not detect them). Nothing is saved.
action actionProjectSettings
expect lineGameTitle RPG Maker 2003 Test suite
expect comboEncoding Detect automatically
check-layout
tab tabs 1
expect labelEngine RPG Maker 2003
# its RPG_RT.exe is a stub
expect labelRuntime RPG_RT.exe: unknown version
expect comboTextFont Font 1 (MS Gothic)
check-layout
tab tabs 2
# keys the Editor does not show: EasyRPG.ini as written
expect comboPatchMode As written in EasyRPG.ini
expect-option-enabled comboPatchMode 0 off
expect-checked patchDynRPG on
expect-checked patchKeyPatch on
expect-checked patchManiac off
expect-enabled patchManiac off
expect labelOtherPatches AntiLagSwitch
set-control comboPatchMode 1
expect-enabled patchManiac on
check-layout
close
quit
