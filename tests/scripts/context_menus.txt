# The right-click menus open where they are clicked, their top-left corner
# on the pointer (Ez.ContextMenu, a window of its own): on a node of the map
# tree not selected, then on the same node selected (its map shown), on
# another node, low in the tree (the bottom of the main window: a menu drawn
# in the window was pushed up inside it), and above the point where the
# screen ends. The menu is made again each time, with its items. Then the
# menus of a database list (opened on the press) and of the event commands.
# Run on TestGame-2003 (https://github.com/EasyRPG/TestGame): it opens on
# its map "call"; the third line of the tree is "Picture events".
expect-not treeMap > Picture events
view-click treeMap 40 45 right
wait 300
expect treeMap > Picture events
expect-menu-at treeMap 40 45
expect-enabled Copy Map on
key Escape
wait 300
expect-not treeMap > Generate Dungeon
# the same node, selected now
view-click treeMap 90 47 right
wait 300
expect treeMap > Picture events
expect-menu-at treeMap 90 47
expect-enabled Copy Map on
key Escape
wait 300
# a node lower in the tree
view-click treeMap 60 100 right
wait 300
expect-not treeMap > Picture events
expect-menu-at treeMap 60 100
key Escape
wait 300
# where the screen ends (800x800 offscreen): over the point
resize 1024 780
wait 300
view-click treeMap 40 120 right
wait 300
expect-menu-at treeMap 40 120
key Escape
wait 300
