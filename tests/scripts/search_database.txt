# Edit > Search: a result in a common event or a monster group opens the
# database there (DatabaseWindows::open), at its entry, its battle event
# page and its line.
# Nothing is saved.
# Run on TestGame-2003 (https://github.com/EasyRPG/TestGame).
action actionSearch
wait 400
set-control filter_type 5
focus search_text
type Yeah this code
key Return
wait 500
expect list_result Monster Groups | 89: Test Battle | 2 |
focus list_result
key Down
key Return
wait 800
expect DatabaseDialog Database
expect commands > Comment: Test Comment. Yeah this code
close
wait 300

action actionSearch
wait 400
set-control search_text ""
focus search_text
type Damage:
key Return
wait 500
expect list_result Common Events | 5: CE Fight Test |
focus list_result
key Down
key Return
wait 800
expect DatabaseDialog Database
expect commands > Message: Damage:
close
wait 300
quit
